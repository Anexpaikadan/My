# 3D app icons

Images from **Microsoft Fluent Emoji** (3D style) — https://github.com/microsoft/fluentui-emoji
Licence: MIT, Copyright (c) Microsoft Corporation. Resized to 128×128 WebP.

To change an icon, replace the `.webp` file with the same name (square, transparent background, 128×128 is enough).
Which file each module uses is set in `includes/icons.php` → `app_modules()` / `admin_modules()`.
